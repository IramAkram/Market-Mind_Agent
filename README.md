**MarketMind AI --- Research Intelligence Platform**
MarketMind AI is a Streamlit-based business research dashboard designed
to organize market research workflows in one workspace. It provides an
interface for configuring research briefs, previewing an agent pipeline,
reviewing report quality, managing human approval, and viewing
session-level analytics.
**Features**
- Modern dashboard: Dark glassmorphism-inspired design, gradient
  backgrounds, responsive layout, and research-themed imagery.
- Workspace access screen: API-key entry screen with basic
  key-format validation.
- Research Studio: Select a research scenario, write a custom
  brief, and configure iteration count, model temperature, budget
  ceiling, and report style.
- Pipeline preview: Displays the main workflow stages: request
  analysis, research planning, tool dispatch, evidence analysis, and
  report synthesis.
- Report preview: Presents a sample executive summary and research
  findings.
- Quality Control: Includes an audit overview and a manual
  reviewer checklist.
- Human Approval Center: Supports approve, request revision, and
  reject actions for the current report.
- Analytics: Shows session-level research activity and configured
  budgets.
- Research History: Lists reports created during the current
  Streamlit session.
- Report export: Download reports as Markdown files.
   **Technology Stack**
- Python --- application logic
- Streamlit --- interactive web application
- Pandas --- tabular data and analytics
- python-dotenv --- environment variable loading
- HTML and CSS --- custom visual styling
